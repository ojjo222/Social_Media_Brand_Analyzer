# Social Media Brand Sentiment & Complaint Clusterer

## Project Overview
This project analyzes brand-related comments from social media, identifies sentiment, and groups negative feedback into complaint categories.

## My Contribution
- Processed clustered comment data using Pandas.
- Assigned readable complaint categories to clusters.
- Summarized complaint counts.
- Developed an interactive dashboard using Streamlit and Plotly.
- Displayed complaint details and platform comparisons.

## Technologies Used
- Python
- Pandas
- Streamlit
- Plotly
- BERTopic (planned advanced topic-modeling component)

## How to Run
1. Install the required libraries.
2. Run `python topic_model.py`.
3. Run `python -m streamlit run app.py`.

Note: Sample comments are synthetic and are used only for development and testing.
